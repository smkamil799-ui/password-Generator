\# 🔐 Password Generator



A beginner-friendly Python project that generates random passwords.



\## ✨ Features



\- Generate random passwords.

\- Choose your password length.

\- Uses Python's `secrets` module for secure random generation.

\- Simple and easy-to-understand code.



\## 🛠️ Technologies Used



\- Python 3

\- `secrets` module

\- `string` module



\## 🚀 How to Run



1\. Install Python 3.

2\. Download or clone this repository.

3\. Open a terminal in the project folder.

4\. Run the command:



&#x20;  ```bash

&#x20;  python password\_generator.py

&#x20;  ```



5\. Enter the desired password length.
